# Portfólio Pessoal – João Victor Contarim

Este repositório contém o código do meu portfólio pessoal, desenvolvido com o objetivo de apresentar meus projetos, habilidades e trajetória na área de desenvolvimento de software.

O site funciona como uma vitrine dos projetos que venho desenvolvendo ao longo dos meus estudos, além de demonstrar minhas habilidades em desenvolvimento web e organização de interfaces.

# Sobre o projeto

O portfólio foi desenvolvido como uma aplicação web estática, com foco em simplicidade, organização e apresentação clara das informações.

Por meio dele é possível conhecer um pouco mais sobre minha trajetória, visualizar as tecnologias que utilizo e acessar alguns dos projetos que desenvolvi durante meu processo de aprendizado.

A página conta com seções como:

Apresentação pessoal

Tecnologias e habilidades

Projetos desenvolvidos

Links para contato e redes profissionais

O principal objetivo do projeto é centralizar minhas informações profissionais e facilitar o acesso aos meus trabalhos e experiências na área de tecnologia.

# Tecnologias utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- HTML

- CSS

- JavaScript

# Objetivo do projeto

Este portfólio foi criado com os seguintes objetivos:

Apresentar meus projetos e estudos na área de programação

Demonstrar minhas habilidades em desenvolvimento web

Criar um espaço centralizado para recrutadores e pessoas interessadas conhecerem meu trabalho
